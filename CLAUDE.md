# Dark Mode Lab — правила проекта

Это YouTube-лаборатория: два канала (RU + EN) с одним конвейером. Тёмные и странные истории о том, как ломаются системы, которым все доверяют: наш разум, сама наука и технологии. Каждый выпуск — конкретная история, которая подводит к одному большому вопросу (решение 27.10.2026: тема расширена наукой и философией). Полный устав: `docs/устав.md` (источник истины — Claude Doc «Dark Mode Lab — устав канала»).

Этот проект НЕ связан ни с какими другими каналами пользователя. Не упоминай их и не переноси их правила сюда.

## Скиллы и движок
- Единственный моушн-скилл: **obsion-motion**, целиком (разведка → `plan/creative.md` → три питча и аниматик → раскадровка → ассеты → сборка → `render.cjs` → `watch.py` + `layout_check.mjs`). Критик выключен, пока пользователь не попросит.
- Движок — obsion (HTML + GSAP, `depth25.js`, `camlife.js`, `sfx.js`). **Remotion и vizavi-motion не используются.**
- Переопределения obsion для этого канала: библия стиля, шаблоны сцен и каталог мемов делаются один раз и переиспользуются (правило «ассеты не переиспользуем» снято). Персонажа в кадре нет — рассказчик за кадром.
- Ссылки obsion на папки `content/youtube/...` его владельца — игнорировать, у нас свои эталоны в `episodes/`.
- Генератор картинок — Gemini (подписка есть), запасной — Canva. codex-image не используем.

## Стиль (утверждён 26.10.2026, обновлён 27.10.2026, `art/style_bible.txt`)
Тёмный минимализм + кинетическая типографика, эдит-приёмы на мем-битах и хуках. Заголовки — Oswald 700, текст — Inter, служебное — IBM Plex Mono, пометки — Caveat. Один акцент — красный `#E5392B`. Реальные документы и мемы вставляются как есть, в своих рамках.
**Настоящее вместо сгенерированного (правило от 27.10.2026):** максимально везде — реальные фото, документы, графики из статей, настоящие иконки и логотипы (в превью тоже). Рисованное/сгенерированное — только когда реального нет; ассет-схема поверх реального фото допустима.

## Формат
- 10–15 минут (решение 27.10.2026; было 6–8) + один пилот «кроличья нора» ~30 мин — сравнить удержание. Горизонталь 1920×1080 60 fps, −14 LUFS.
- Один выпуск → два рендера (RU, EN): общие сценарий, картинки, тайминг; отличаются голос и текст на экране. Выходят в один день.
- Голос (27.10.2026): ElevenLabs, «Oleg», voice_id `MWyJiWDobXN8FX3CJTdE` (RU); EN — уточняется. Ключ `ELEVENLABS_API_KEY` в `.env`. Генерация — с платного тарифа (коммерческая лицензия).
- Из каждого выпуска 1–2 вертикальных шортса.
- Темп: 2 выпуска в неделю, 12 выпусков за 6 недель, по 4 на полосу, вперемешку.

## Три полосы
(с 27.10.2026)
A — **Разум**: философские вопросы (свобода воли, память, восприятие, идентичность) через реальные эксперименты, случаи и дела · B — **Наука изнутри**: как ломается наука и измерения (подделки, ошибки, эталоны, эксперименты не туда) — по отчётам комиссий и ретракциям · C — **Технологии**: технокатастрофы, взломы, аферы, как устроено то, чем мы пользуемся.
Формат и стиль одинаковы для всех трёх. От формата «рассуждений» берём главное: выпуск держится на вопросе, история — способ к нему подойти. Космос/сознание/симуляция «вообще» не берём — это самая забитая ИИ-фермами ниша.

## Отбор тем: «ИИ-копии ещё не дошли» (правило от 27.10.2026)
- Знаменитые истории уже массово пересказаны безликими ИИ-каналами (Knight Capital: ~25 почти одинаковых роликов за 1–4 месяца, 13–400 просмотров). Тема сама по себе не преимущество.
- Тема идёт в работу, только если поиск YouTube в EN **и** RU показывает **не больше 2–3 роликов за последние 90 дней**. Проверка — перед стартом выпуска, результат записывается в `lab/topics.md`.
- Искать там, куда фермы не доходят: свежие разборы инцидентов 2025–2026; отчёты регуляторов и судов на польском, голландском, немецком и других языках; малоизвестные дела из первоисточников.
- Не прошла проверку — в резерв, не в работу.

## Сценарий (устав, раздел 7)
- История с нитью, не слайды. Хук в первые 30 с, открытая петля каждые 60–90 с, награда (мем / цифра / документ) каждые 15–20 с. Главный ответ — только в развязке.
- Тон: умный друг за столом. Взрослый, сухой юмор, честный, уважительный к людям. Длинные связные фразы; никаких рубленых слоганов и «ИИ-стиля».
- Ни одного утверждения без источника: минимум 3 источника на ключевой факт, `sources.csv`, каталог реального материала `source-media/real/CATALOG.md`. Непроверенное помечается «НЕ ПРОВЕРЕНО» и в ролик не идёт.
- Мемы — существующие и узнаваемые, один на бит, в конкретном месте, с конкретной эмоцией, со своим звуком. Статичные и гифки без звука — свободно; клипы со звуком — ≤ 3 с, свой звук поверх.
- RU и EN — один характер, не перевод: заголовки, идиомы и мемы адаптируются под рынок.

## Безопасность контента (устав, раздел 15) — проверяется по сценарию ДО рендера
- Трагедии: фокус на механике, без крови/тел/моментов гибели, без смакования, не младше года.
- Скамы и взломы: «как это работало», никогда «как повторить». Без кода эксплойтов, пошаговых инструкций, шаблонов фишинга. Обязательно «как защититься».
- Люди и компании: факты только из источников; оценки — только по суду/расследованию. Личные данные обрезаем. Чужие голоса и лица не подделываем.

## Источники картинок (скрипты в `scripts/`, запускаются на Маке)
Проверка темы на YouTube: `scripts/yt_check.py topics.txt` (YouTube Data API, ключ `YOUTUBE_API_KEY` в `.env`) — счёт роликов за 90 дней EN/RU + просмотры, результат дописывается в `lab/topics.md`.
Klipy (гифки) · Know Your Meme (мемы) · Wikimedia Commons API (история, документы) · Pixabay API + Unsplash (фото/видео) · headless Chrome (скриншоты статей).
**Unsplash подключён как плагин (27.10.2026):** инструменты `mcp__Unsplash__*` (search_photos, search_illustrations, download_asset…) — пользоваться для фонов, фото и иллюстраций в роликах и превью; скачивать только через `download_asset` (он регистрирует загрузку), атрибуция автора — в каталог выпуска.
**Скачивание с Commons/внешних сайтов** — через Desktop Commander на Маке (облако и VM-оболочка в Commons не пускают), затем `device_stage_files`. **Giphy, Tenor, Pexels не используются.** Ключи — только в `.env` (в git не попадает). Скачивание — после ОК пользователя со списком (имя, источник, размер). Каждый файл в каталоге с лицензией.

## Порядок работы с пользователем
- Три варианта заголовка и превью → выбор пользователя → только потом сценарий. Превью показываются отрендеренными макетами (+ проверка в размере ленты).
- Превью: тема понятна с первого взгляда — название истории + строка-ключ + настоящие материалы. Делается по разделу «Превью» библии стиля (`art/style_bible.txt`).
- Сценарий утверждает пользователь. Питч и раскадровку выбирает пользователь. Контактный лист картинок → выбор пользователя.
- Первая сборка всегда показывается как «черновик». Правки точечные, ролик целиком не пересобирается.
- Хронометраж по этапам в `lab/journal.md`: если выпуск > 8 часов к третьему разу — упрощаем пайплайн.
- Метрики через 7 дней после выхода → `lab/journal.md`. Решения по полосам/языкам — только по таблице (устав, раздел 12).
- На время эксперимента не меняем: стиль, голос, длину, число полос.
- В конце каждого рабочего дня — запись в `lab/diary.md` (свежие сверху): что сделали · что решили · чему научились · слабые места · что дальше.

## Папки
- `episodes/<YYYY-MM-DD>_<slug>/` — всё по выпуску (структура в `episodes/_template/`).
- `видео/<полоса>/`, `видео/обложки/`, `видео/шортсы/` — готовые файлы для загрузки (в git не попадают).
- `assets/` — постоянное: шрифты, фактуры, рамки, каталог мемов/гифок. `templates/scenes/` — шаблоны сцен obsion.
- `lab/` — журнал эксперимента, банк тем и дневник итогов дня (`diary.md`). `docs/` — устав и правила.
