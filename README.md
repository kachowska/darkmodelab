# Dark Mode Lab

YouTube-лаборатория: два канала (RU `@darkmodelab_ru` · EN `@darkmodelab`) из одного конвейера.
Тёмные и странные истории из мира технологий и интернета — и как на самом деле устроено то, чем мы пользуемся.

- Правила для Claude: `CLAUDE.md` · Устав: `docs/устав.md` · Стиль: `art/style_bible.txt`, эталон `art/style-reference.png`
- Пайплайн: obsion-motion целиком. Шаблон выпуска: `episodes/_template/`
- Новый выпуск: `scripts/new_episode.sh <slug>`
- Картинки: `scripts/find_assets.py episodes/<ep>` (ключи в `.env`, см. `.env.example`)
- Журнал эксперимента и банк тем: `lab/`
- Готовые файлы для загрузки: `видео/` (не в git)
