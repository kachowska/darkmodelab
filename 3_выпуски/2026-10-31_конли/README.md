Создаётся командой `4_инструменты/новый-выпуск.sh <slug>` (копия этого шаблона + движок глав в `сборка/`).

## Папки выпуска
| Папка | Что внутри |
|---|---|
| `план/` | `titles.md` (заголовки и превью), `creative.md` (файл креатива obsion), `safety.md` (проверка безопасности), `publish.md` (описание для YouTube) |
| `сценарий/` | `ru.md`, `en.md` (для общих выпусков) |
| `материалы/` | `настоящие/` фото, видео, документы, скриншоты · `мемы/` · `музыка/` · `вырезки/` · `каталог.md` (каждый файл с источником и лицензией) · `источники.csv` (каждое утверждение — 3 источника) |
| `превью/` | только финальные превью: `превью.html`, `превью-ru.jpg`, `превью-en.jpg` |
| `сборка/` | главы ролика `hook/`, `ch1/`…, движок `lib/`, кадры клипов `media/`, план музыки `music_plan.json`, скрипты рендера |
| `готово/` | последний собранный ролик, `.srt`, описание — то, что смотрит пользователь и что уходит в `5_готовые-видео/` |

Всё временное (пробы, контактные листы, кадры проверок, логи) — в `_черновики/<выпуск>/` в корне проекта.
