`шрифты/` — все шрифты проекта с лицензиями OFL и `fonts.css`; `фактуры/`, `рамки/` — фактуры и рамки для сцен; `мемы-каталог.md`, `гифки-каталог.md` — каталоги мемов с лицензиями.
