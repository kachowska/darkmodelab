# Движок глав Dark Mode Lab (эталон — выпуск «Перитоны», 28.10.2026)

Копируется в `3_выпуски/<выпуск>/сборка/` в начале сборки: `lib/` ← dml.js, dml.css, prep_media.py; в `сборка/` ← render_ch.sh, render_mac.sh, assemble.sh.

- `dml.js` — слова и тайминг под голос (`DML.words`, `wt('слово')`), клипы и гифки покадрово (`DML.seqs`), пыль и «дыхание» объектов, **перебивки** `DML.inserts(tl, EV, [[t, 'seq:имя' | 'файл', dur, 'full'|'tilt'|'circ', подпись, css]])`.
- `dml.css` — общие стили: документы, полароиды, мемы, старый телевизор, круги, перебивки.
- `prep_media.py spec.json` — клипы и гифки → кадры в `сборка/media/<имя>/` + `meta.js`.
- Глава = `сборка/chN/index.html` (эталоны — главы «Перитонов»): SENT → `DML.words`, сцены `show/ent/slam/meme`, камера `CAMLIFE`, звук `EV` + `SFX`, `window.__seek` возвращает `DML.seqs`.
- Перед рендером — `node 4_инструменты/анимация-obsion/pace_check.cjs сборка/chN/index.html` (цели — раздел «Темп» библии стиля).
- Рендер на Маке: `J=4 сборка/render_mac.sh` (≈ 12 мин на выпуск 10 мин), склейка и мастеринг — `assemble.sh`.
- Первичная настройка Мака — `4_инструменты/движок-глав/настройка-мака.sh`.
- Проверка длины кадров — `node 4_инструменты/анимация-obsion/shot_check.cjs сборка/chN/index.html` (сцену видно ≥ 2,5 с до перебивки и ≥ 2 с после).
- Звук: `audio_only.cjs` — звуки главы без музыки; музыка из треков — `4_инструменты/звук/music_mix.py сборка/music_plan.json` (результат — в `готово/`).
- Новый выпуск получает этот движок автоматически: `4_инструменты/новый-выпуск.sh <slug>`.
